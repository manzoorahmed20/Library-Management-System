
# Library Management System

A Library Management System built with Python, Streamlit, and SQLite.

## Features

- Add and view books
- Search books by title and author
- Register Student and Teacher members
- Issue and return books
- Automatic due dates
- Late return fine calculation
- Borrowing limits for Students and Teachers
- Overdue books report
- Delete books

## Technologies

- Python 3
- Streamlit
- SQLite
- Pandas (optional)

## How to Run

Install the required packages:

```bash
pip install streamlit pandas
```

Run the application:

```bash
python -m streamlit run main.py
```

The SQLite database is created locally when the application runs.
